🌐 1. Project Overview & Motivation

Introduction

🎯 What is StayEase?

An intelligent web-based reservation platform combining hotel bookings and restaurant table reservations into a unified modern experience.


Features an integrated AI Booking Assistant and autonomous agentic workflow to eliminate manual searching friction.

📍 Key Coverage & Highlights

  • 18 Top Hotels: Verified luxury to budget stays
  • 18 Restaurants: Multi-cuisine & fine dining options
  • 8 Major Cities: Delhi, Mumbai, Jaipur, Bangalore, Goa, Agra, Chennai, Hyderabad
  • Modular REST API: High performance & decoupled architecture

⚠️ 2. Problem Statement

Problem Analysis

1. Fragmented Systems

Travelers must navigate separate platforms for accommodation and dining, resulting in disjointed travel itineraries and multiple accounts.

2. Rigid Search Interfaces

Standard platforms rely strictly on complex filters, dropdowns, and pagination, which often fail when users express natural constraints.

3. Lack of Agentic Automation

Traditional booking engines cannot autonomously parse requests like 'Find a 5-star hotel in Goa under ₹8000 for 2 guests' in one step.

🎯 3. Project Objectives

Scope & Goals

Core Engineering Objectives

  • Develop a responsive, framework-free frontend for maximum speed and simplicity.
  • Build a modular REST API backend in Python Flask with clean Blueprint routing.
  • Implement room availability checking and table reservation logic with price calculation.

AI & Automation Objectives

  • Design a conversational AI Assistant capable of entity extraction (City, Date, Guests, Budget).
  • Implement an Agentic Worker executing multi-step autonomous tasks with traceable states.
  • Provide flexible MongoDB storage for persistent reservation lifecycle management.

📦 6. Major System Modules

Implementation

🏨 1. Hotel Management Module

Handles catalog search across 8 cities with multiple filters (price bounds, star ratings, capacity). Calculates stay prices dynamically based on room type selections.

🍽️ 2. Restaurant Module

Manages dining venues, table sizes, opening hours, and cuisine filtering. Incorporates location-based querying for nearby restaurants.

📑 3. Unified Booking Engine

Orchestrates booking lifecycles with status tracking (confirmed, cancelled, pending) and unique UUID generation.

🤖 4. AI & Agent Execution Module

Powers real-time natural language inquiries and multi-step agent execution with transparent step-by-step trace reporting.

🧠 7. Conversational AI Assistant

AI Engine

Intent Classification

  • GREET / HELP: Conversational guidance & instructions
  • SEARCH_HOTEL: Filters city, guest count, price & stars
  • SEARCH_RESTAURANT: Filters dining slots & party size
  • BOOKING_STATUS / CANCEL: Directs reservation actions
  • NEARBY: Triggers browser geolocation queries

Multi-Turn Session State

User: "Find a hotel for 2 guests" └─► State: {guests: 2, missing: 'city'} AI: "Which city are you travelling to?" User: "Mumbai" └─► State: {guests: 2, city: 'Mumbai'} AI: "Found 3 hotels in Mumbai..." + Quick Replies

⚡ 8. Autonomous Agentic Booking Worker

Autonomous Workflow

The AgentWorker decomposes high-level instructions (e.g. "Book a 5-star hotel in Jaipur for 2 guests on Nov 15") into a 7-stage plan:

Step # Step Name Description & Action Status in Trace
1 understand_request Regex entity extractor identifies city, dates, budget, party size Done
2 search_catalogue Queries hotel / restaurant catalog with parsed criteria Done
3 check_availability Verifies real-time room / table inventory Done
4 present_options Ranks best matches and presents structured choices Done
5 - 7 await & execute Pauses safely for user confirmation before inserting database record Needs Input

🏁 12. Challenges, Future Scope & Conclusion

Summary & Q&A

Technical Challenges Overcome

  • Stateful NLP: Managing multi-turn intent continuation across stateless HTTP calls.
  • Agent Transparency: Designing step-wise execution traces so users see what the agent is doing.
  • Resilient Architecture: Ensuring the app runs in mock mode even when MongoDB is offline.

Future Roadmap & Conclusion

  • Integration with live payment gateway (Razorpay) and SMS/Email confirmation webhooks.
  • Fine-tuning with Gemini API for unstructured itinerary planning.
  • Conclusion: StayEase delivers an efficient, full-stack, AI-augmented reservation experience built on clean modular code.
